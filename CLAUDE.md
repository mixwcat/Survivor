## Naming Conventions

- **Private fields**: `_camelCase` with underscore prefix (e.g., `_entityData`, `_lineRenderer`)
- **Public/Unity-serialized fields**: `PascalCase` (e.g., `StatModel`, `detectionCollider`)
- **Methods/Properties**: `PascalCase` (e.g., `GetStat()`, `ApplyTo()`)
- **No namespaces** used in game code (global namespace), except third-party `LitJson` library
- **ScriptableObject assets**: suffix with `SO` (e.g., `PlayerDataSO`, `LevelUpSO`)
- **Unity API**: Use `FindFirstObjectByType<T>()` not deprecated `FindObjectOfType<T>()`

## Core Architecture: EDM (Entity Data Model)

The entire gameplay runs on a **data-driven stat system** under `Assets/Script/Core/Entity/`:

```
EntityBehaviour (MonoBehaviour base class for all gameplay entities)
  └── EntityStatModel (runtime stat container: base values + modifiers)
        ├── StatType enum — single global enum for ALL entity stats
        ├── StatDefinition — pairs a StatType with a base value
        ├── StatModifier — runtime modifier (Add/Multiply/Override) with a Source reference
        └── StatModifierData — serializable struct for SOs to declare modifications
```

**How it works**:
1. `BaseEntityDataSO` (abstract ScriptableObject) declares stat base values. Subclasses: `PlayerDataSO`, `TowerDataSO`, `WeaponDataSO`, `EnemyDataSO`.
2. `EntityBehaviour.Awake()` calls `_entityData.FillStatModel(StatModel)` to populate runtime stats.
3. `EntityStatModel.GetStat(type)` computes final value: `(base + ΣAdd) * (1 + ΣMultiply)`, or raw value if Override exists.
4. `LevelUpSO.ApplyTo(entity)` adds `StatModifier` entries into the target's `StatModel` — **upgrades are entirely data-driven**, no code changes needed.

**Entity hierarchy**:
- `EntityBehaviour` → `BaseTower` (towers: Teto/Rin/Luo)
- `EntityBehaviour` → `BaseWeapon` → `SpinWeapon` (fireball), `GunWeapon` (shotgun)
- `EntityBehaviour` → `PlayerController`
- `EntityBehaviour` → `EnemyController`

## Input Architecture

**设计目标**：平台无关的输入抽象层，支持 Windows（键盘+鼠标）和 Android（触屏+摇杆），并为未来联机模式预留扩展点。

### 核心接口

`IInputHandle` (`Assets/Script/InputSystem/IInputHandle.cs`) — 统一输入接口，业务代码只依赖此接口：

```csharp
public interface IInputHandle
{
    // 移动输入（轮询读取）
    Vector2 MoveInput { get; }
    
    // 攻击方向输入（Android: 摇杆方向，Windows: 通过 ScreenPointerPosition 计算）
    Vector2 AttackDirectionInput { get; }
    Vector2 ScreenPointerPosition { get; }
    
    // 世界触控（塔放置等，自动过滤 UI 区域）
    bool TryGetWorldPointer(out Vector2 screenPos, out bool isDown, out bool isUp);
    bool HasCancelInput { get; }  // 右键/ESC
    
    // 交互事件（E 键/UI 按钮）
    event System.Action OnInteract;
    event System.Action OnEscape;
}
```

### 平台实现

**Windows 平台** (`PCInputHandle.cs`)：
- 适配 `InputReader` (ScriptableObject)，桥接 Unity 新版 Input System
- `MoveInput` → 代理到 `InputReader.MoveInput` (WASD/方向键)
- `ScreenPointerPosition` → `Input.mousePosition`
- `TryGetWorldPointer` → 始终返回鼠标位置
- `HasCancelInput` → 鼠标右键

**Android 平台** (`MobileInputHandle.cs`)：
- 适配 `Joystick Pack` 插件
- `MoveInput` → 左摇杆 `Direction`
- `AttackDirectionInput` → 右摇杆 `Direction`
- `TryGetWorldPointer` → 使用 `EventSystem.IsPointerOverGameObject()` 过滤 UI 触控（摇杆区域）
- `HasCancelInput` → 返回 `false`（Android 无物理取消键）
- 提供 `TriggerInteract()` / `TriggerEscape()` 供 UI 按钮调用

### 工厂创建

`InputHandleFactory.GetLocalInput()` 根据编译平台（`#if UNITY_STANDALONE_WIN` / `#elif UNITY_ANDROID`）自动创建对应实例：
- Windows: `new PCInputHandle(InputReaderManager.Instance.inputReader)`
- Android: `new MobileInputHandle(joysticks[0], joysticks[1])`
- 未来扩展点：`CreateNetworkInput()` (联机模式)、`CreateAIInput()` (AI 玩家)

### 使用示例

```csharp
// 所有业务代码统一使用
private IInputHandle _inputHandle;

void Awake()
{
    _inputHandle = InputHandleFactory.GetLocalInput();
}

void FixedUpdate()
{
    // 轮询读取移动输入
    Vector2 move = _inputHandle.MoveInput;
    rb.linearVelocity = move.normalized * speed;
}

void OnEnable()
{
    // 订阅交互事件
    _inputHandle.OnInteract += HandleInteract;
}
```

### 调用链示例

**场景 1：WASD 移动玩家**
```
键盘 → Unity Input System → InputReader.OnMove() [存储 Vector2] 
→ PCInputHandle.MoveInput [代理] → PlayerController.FixedUpdate() [轮询读取] 
→ Rigidbody2D.linearVelocity [物理移动]
```

**场景 2：ESC 打开暂停菜单**
```
键盘 → Unity Input System → InputReader.OnEscapePress() [触发事件] 
→ PCInputHandle.OnEscape [事件代理] → GameLevelManager.ShowSettingPanel() [订阅者] 
→ UIManager.ShowPanel<PausePanel>() [加载 UI]
```

### 架构优势

- **依赖倒置**：业务代码只依赖 `IInputHandle` 接口，不依赖具体平台实现
- **平台隔离**：所有 `#if` 宏集中在 `InputHandleFactory` 一处，业务代码无平台判断
- **自动过滤**：`TryGetWorldPointer` 自动过滤 UI 触控，避免塔放置时误触摇杆
- **易于扩展**：工厂模式预留联机/AI/回放输入扩展点
- **轮询 vs 事件**：移动输入用轮询（高频），交互事件用订阅（低频）

### 遗留组件

- `InputReader` (ScriptableObject) — 保留，作为 Windows 输入的底层适配器
- `InputReaderManager` (MonoBehaviour) — 保留，持有 `InputReader` 实例供工厂使用
- `InputSystem_Actions` (自动生成) — Unity Input System 的 C# 绑定类

## Tower System

### Tower Placement (防御塔放置)

**Key scripts**:
- `TowerPlacementController.cs` (`Assets/Script/Entity/Tower/`) — drag-and-place ghost sprite
- `ChooseTowerPanel.cs` (`Assets/Script/UI/GamePanel/`) — tower selection UI
- `GamePanel.cs` (`Assets/Script/UI/GamePanel/`) — holds confirm/cancel buttons (mobile only)

**Deleted (no longer used)**: `TowerSpriteController.cs` (old two-stage click intermediate layer)

**Flow**:
```
ChooseTowerPanel button click
→ Instantiate TowerPlacementController from "Prefabs/SpriteToHandle"
→ Drag phase (platform-specific movement)
→ Confirm: Instantiate actual tower prefab, destroy ghost
→ Cancel: Destroy ghost only
```

**Platform differences**:

| | Windows (`UNITY_STANDALONE_WIN`) | Android (`UNITY_ANDROID`) |
|---|---|---|
| **Spawn position** | Mouse world position | Screen center |
| **Movement** | Direct mouse follow + grid snap | Touch delta drag (relative movement, not snapping to finger) |
| **Confirm** | Left mouse click | `GamePanel.btnPlaceTowerConfirm` button |
| **Cancel** | Right mouse click | `GamePanel.btnPlaceTowerCancel` button |
| **Buttons shown** | None | Confirm + Cancel (top-right of GamePanel) |

**Notes**:
- `TowerPlacementController` uses `#if` macros in `Update()` for platform-specific input handling
- Android spawns at screen center because the player's finger will be on the shop button; dragging then moves the sprite relative to finger movement
- `GamePanel.SetTowerPlacementButtonsActive(bool, TowerPlacementController)` shows/hides buttons and stores the controller reference for callbacks
- Collision detection (green/red color) checks against tags: Player, Enemy, Tower
- Grid snapping via `GetGridCenter()` with configurable `gridSize`

### Existing Towers

`BaseTower` (`Assets/Script/Tower/`) features:
- `CircleCollider2D` for enemy detection (radius auto-synced from `StatType.TowerAttackRange`)
- `LineRenderer` for attack range visualization (fades out over time)
- Enemy tracking via `OnTriggerEnter2D/Exit2D`, target selection picks first enemy in range
- Concrete towers: **Teto** (ranged attack projectiles), **Rin** (melee AoE), **Luo** (healing tower)

## Upgrade System

`LevelUpSO` (ScriptableObject in `Assets/Script/SO/`) defines upgrade options displayed in `LevelUpPanel` / `TowerLevelUpPanel`:
- `statModifiers: List<StatModifierData>` — data-driven stat changes
- `fullHeal` / `bonusHeal` — heal effects
- `onApplyEffect` — UnityAction for weapon-selection side effects (used by `ChooseWeaponPanel`)
- `ApplyTo(EntityBehaviour)` applies all modifiers to the target's `StatModel`

## Weapon Selection Flow

`ChooseWeaponPanel` → offers `LevelUpSO` choices → on selection, fires `onApplyEffect` → `WeaponManager` activates the corresponding weapon GameObject → weapon registers itself via `BaseWeapon.OnEnable()`.

## Important Patterns

- **Time usage**: UI animations use `Time.unscaledDeltaTime`; gameplay uses `Time.deltaTime`
- **Panel prefabs**: Must be in `Assets/Resources/UI/` and named identically to their class name
- **Adding new stats**: 
  1. Add to `StatType` enum in `Assets/Script/Core/Entity/StatType.cs`
  2. Set base value in the corresponding `*DataSO.FillStatModel()` override
  3. Create `LevelUpSO` assets for upgrades
- **`.meta` files**: Auto-generated by Unity; never manually edit or delete
- **FindObjectOfType**: Always use `FindFirstObjectByType<T>()` (Unity 6+ API)
