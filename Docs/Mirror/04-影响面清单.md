# 联机改造影响面清单（逐文件详表）

> 目标形态：**2-4 人联机合作**，**服务端权威玩法**（敌人/塔/推车/掉落/结算）+ **客户端权威玩家移动**。
> 本文只写「现状 + 影响 + 需要什么同步手段」，**不含改造实现代码**。
> 所有结论均可追溯到 `文件:行`；无法确认的写「不确定」，不编造。
>
> 覆盖范围：`Assets/Script/` 下全部业务代码（`Util/Json/LitJson/` 第三方与 `InputSystem/InputSystem_Actions.cs` 自动生成绑定除外，后者只做类名/接口级确认）。
> 生成方式：逐文件 `read` + 全项目 `grep`（static / Instantiate / event / 生命周期），未运行 Unity、未读 `.prefab`/`.asset` 二进制之外的内容（资产名由 `Assets/Game/Prefabs` 目录清单 + 代码里的 `AssetReference`/SO 字段推断）。

### 7.3 给改造计划的"最小冲突面"提示（仅陈述代码事实，不含实现）
