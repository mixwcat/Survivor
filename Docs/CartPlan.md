| | 内容 |

## 2. 故事与目标

一个组织要把物资运往很远的地方，沿途设了很多哨站。
玩家接下悬赏，把物资从**当前哨站**运到**下一个哨站**；运到了才有钱，有钱才能接更远的悬赏。
**每进入下一个哨站，怪物难度上升。**

第一阶段只做**第一段**：哨站 1 → 哨站 2。

## 3. 角色（本阶段 2 个）

| | **枪手** | **工程师** |
|---|---|---|
| 默认武器 | `gun`（后续可解锁大炮、激光） | `spin`（火球环绕） |
| 武器升级 | ✅ 局内界面 | ❌ 无 |
| 防御塔 | ❌ 无 | ✅ 建造 / 升级 / 拆除 |
| 定位 | 机动输出 | 阵地控场 |

**功能互斥是本阶段的核心设计**：GamePanel 上**同一个入口按钮**，枪手打开是武器升级界面，工程师打开是塔管理界面。
角色差异不只是数值，而是**能做什么**。

## 4. 等待界面（新场景 `Lobby`）

流程：`选角色 → 大厅乱逛 → 传送门集合 → 出发`

| 环节 | 设计 |
|---|---|
| 选角色 | 进入大厅弹出选角面板：2 张卡，显示武器、定位、特色 |
| 大厅 | 2D 俯视房间，可自由移动；一侧是**武器台**（花金币解锁武器） |
| 传送门 | 玩家进入范围并停留 1 秒 → 3 秒倒计时 → 切关卡场景 |
| 出发配置 | 枪手选带哪 2 把武器（从已解锁里选） |
| 大厅常显 | 金币余额、当前哨站进度 |

- 单机下"所有玩家都待在传送门旁"退化为**1 人进圈**；逻辑按多玩家写（遍历 `AllPlayers`），联机时不用改。
- 大厅是**乱逛**的：玩家可以走到武器台、走到传送门，而不是纯菜单。

## 5. 第一关

### 5.1 推进

- 路线：一条**从左到右**的路径，**起点哨站 → 终点哨站**。
- 车**自动向右行驶**（固定速度），玩家在周围护送清怪 —— 不需要玩家推。
- 路程分 **2 段**，每段尽头有一个**充能点**。

### 5.2 充能点与 boss（核心节奏）

```
到达充能点 → 车停下、充能开始
          → boss 出现
          → 击败 boss → 获得充能能源 → 充能完成 → 车继续前进
```

- 第一关共 **2 个充能点 = 2 个 boss**。
- 击败第二个 boss 后，车驶入**终点哨站** → 本局胜利。
- 充能与 boss 的具体关系**待定**（§9-1）：
  - **A**：击败 boss 才给能源，充能瞬间完成（boss 是硬门槛）
  - **B**：充能自动读条，boss 是骚扰（不打死就充得慢 / 会被打断）

### 5.3 小怪

- 沿途**随机刷新**，从**前方堵截**与**后方追击**两个方向靠近。
- **车停下时压力上升** —— 逼玩家尽快解决 boss，而不是无限拖。
- 用现有 3 种敌人（Slime / Soil / Cloud），数值按哨站系数缩放。

### 5.4 胜负

- **胜利**：抵达终点哨站。
- **失败**：全员阵亡。
- 车被打坏 → 只是停下（增加压力），**不直接失败**（避免一次失误就团灭）。

## 6. 局内成长

### 6.1 升级点（通用货币）

- **来源**：击杀敌人掉落（需拾取）+ 每次角色升级额外发放。
- **用途**：枪手升武器 / 工程师造塔升塔。
- 与**经验**的分工见 §9-2：经验 → 角色升级 → 三选一（随机成长）；升级点 → 定向升级（想升哪个就升哪个）。

### 6.2 枪手：武器升级界面

- **入口**：局内随时打开（GamePanel 按钮，复用原塔建造入口的位置）。
- **内容**：当前携带的武器 + 每把可升级的项（伤害 / 射速 / 弹速 / 溅射半径…），消耗升级点。
- **可携带 2 把并随时切换**：键盘 `1` / `2`，手机屏幕按钮。

### 6.3 工程师：防御塔界面

- **建造**：选塔型 → 放置（复用 `ChooseTowerPanel` + `TowerPlacementController`）。
- **升级**：选中已有塔 → 升级（消耗升级点）。
- **拆除**（第三个选项）：返还「建造花费 + 已投入升级花费 **− 1 个升级点**」。

## 7. 局外：金币 / 解锁 / 存档

| 项 | 设计 |
|---|---|
| **结算** | 完成对局 → 金币 = 基础 100 + 哨站系数 × 表现（击杀数 / 车剩余耐久） |
| **失败也给** | 30 金币（避免挫败，但明显少于通关） |
| **解锁** | 大厅武器台：大炮 **800**、激光 **1500**（首版建议值，可调） |
| **存档** | 本地 JSON（`Application.persistentDataPath`）：金币 / 已解锁武器 / 当前哨站 / 音画设置 |

## 9. 待定项（动工前拍板）

| # | 问题 | 建议 |
|---|---|---|
| 1 | **充能与 boss 的关系** | **A**（击败才完成）—— 节奏更明确，也便于后续联机的权威判定 |
| 2 | **现有"升级三选一"是否保留** | **保留，但池子只放角色属性**（移速 / 生命 / 拾取 / 无敌时间），武器与塔的成长全部走升级点。否则武器会有「随机抽到」和「定向买」两条路径，数值叠得过快 |

| 5 | **枪手携带数** | 2 把（与现有 2 个武器槽对齐） |
| 6 | **升级点掉落形态** | 击杀自动入账（少一套拾取流程），先验证节奏 |
